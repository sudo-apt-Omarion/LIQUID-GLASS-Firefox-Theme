## Manual Installation (Core CSS Only)
To configure the open-source files manually, place `userChrome.css` and `userContent.css` into your Firefox profile's `chrome` folder, enable `toolkit.legacyUserProfileCustomizations.stylesheets` in `about:config`, and restart.
